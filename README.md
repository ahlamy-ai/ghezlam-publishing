# GHEZLAM Digital Publishing House

**Ideas That Become Worlds.**

A lightweight, responsive website for GHEZLAM Digital Publishing House. The visual identity uses a dark background, restrained gold accents, and editorial typography.

## Files
- `index.html` — home, catalog, about, and contact sections
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and catalog search

## Add publications
Edit the `publications` array in `script.js`. Each entry can include:
- `title`
- `category`
- `description`
- `url` (a verified book/store page)

Only add confirmed book metadata and working store links. The author/publisher identity is GHEZLAM; each publication keeps its own title.

## Before public launch
1. Replace the placeholder contact email in `index.html` with an address you control.
2. Add verified book titles, descriptions, and purchase links.
3. Enable GitHub Pages in the repository Settings → Pages, using the `main` branch and `/(root)` folder.
4. Confirm the published Pages URL in GitHub before sharing it.

This site does not upload or publish books to Amazon KDP or Google Play Books. Those publishing accounts remain separate.
